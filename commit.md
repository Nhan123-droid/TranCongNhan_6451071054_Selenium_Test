Quy chuẩn commit message

Áp dụng format: <type>: <short description>
Commit bằng tiếng anh
Quy ước type:

feat → thêm tính năng

fix → sửa lỗi

docs → tài liệu

refactor → tối ưu code

test → viết test

chore → config, build, CI

Ví dụ: + feat: implement JWT authentication

+ fix: resolve token validation bug
